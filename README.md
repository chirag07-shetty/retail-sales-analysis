# Retail Sales Analysis

## 📊 Project Overview

Retail Sales Analysis is a data analytics project focused on analyzing retail sales data to identify sales trends, customer purchasing patterns, product performance, and regional insights.

The project uses **Excel, SQL, Power BI, and Python** to clean, analyze, and visualize the data and generate meaningful business insights.

## 🛠️ Tools & Technologies

- Excel – Data cleaning and preparation
- SQL – Data querying and analysis
- Power BI – Interactive dashboards and visualization
- Python – Data analysis and processing

## 📁 Dataset

The dataset contains retail transaction information such as:

- Order ID
- Product
- Category
- Sales Amount
- Payment Method
- Region
- Order Date
- Year and Quarter

## 📈 Analysis Performed

- Sales analysis by product and category
- Sales trends by year and quarter
- Regional sales analysis
- Payment method analysis
- Order volume analysis
- Identification of sales patterns and trends

## 📊 Dashboard

An interactive Power BI dashboard was created to provide a clear overview of sales performance and key business insights.

## 🎯 Project Objective

The main objective of this project is to demonstrate practical data analytics skills by transforming raw retail data into meaningful insights using Excel, SQL, Power BI, and Python.
